Run: node agent-packages/public-incident-triage/run.mjs

Validate offline: node --test agent-packages/public-incident-triage/agent.test.mjs

The runner uses bounded HEAD observations from the three fixed Quest Luxo public website roots. The pilot shares one observation across the three public operations packages. Tests use a synthetic HTTP reader; they cannot prove live availability. Access restrictions and network failures are observations from the checker location, not proof of global outage. The existing pilot schedules this package every five minutes. No new paid infrastructure.
