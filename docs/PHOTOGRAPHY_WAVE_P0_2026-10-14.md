## Per-reference hard release gates

1. Preserve original photo bytes, origin URL/provider, photographer, captured time, model identity, and exact reference/SKU.
2. Record independent legal basis for commercial website use, authorized scope, conditions, expiry and attribution. A product-page URL alone is **not** a license.
3. Confirm photographed dial, case metal, generation, strap/bracelet, and complications against the precise catalog reference. Do not use a near-match, composited dial, or generated/reconstructed watch.
4. Create a natural full-watch, front-facing, balanced white-canvas WEB derivative from the authentic RAW, preserving case, watch proportions, dial and bracelet edges; archive original and SHA-256 hashes.
5. Use existing `approvedPhotograph` review process, exact-configuration link, license record, founder quality approval, website approval, derivative file hash, and source attribution. Never bypass the rights gate.
6. Run `npm run sync:omega-photography:queue` after Omega approvals, then `npm run audit:expansion-photography`, `npm run audit:omega-photography`, full regression suite, visual reference checks, production build and preview.
7. Mark reference complete only when photo is actually rendered in the correct canonical route, no broken image, source attribution is retained, and the watch is in correct configuration.

## Stop conditions

- No documented commercial-use permission -> hold for permission, use truthful image-pending fallback and reference-source link.
- Mismatched watch reference or insufficient photo evidence -> hold; no substitution.
- File missing or SHA-256 altered -> fail CI and restore exact approved derivative.
- Do not merge PR #61 or claim a complete catalog until the photography release gate is actually met.
